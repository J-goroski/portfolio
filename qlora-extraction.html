LLM Filing Extraction (QLoRA)

ML / LLM · Python, Unsloth, Ollama

Overview

A fine-tuning pipeline that adapts a small open model to pull structured fields out of SEC 10-K filings. It fine-tunes Qwen2.5-7B with QLoRA (via Unsloth) and exports the result to GGUF so it runs locally through Ollama — keeping the whole extraction workflow offline and self-hosted.

Pipeline

Data & sync

Built on an existing EDGAR sync module that retrieves and stages 10-K filings, providing the source text the model learns to extract from.

QLoRA fine-tuning

Quantized low-rank adaptation (QLoRA) makes it possible to fine-tune a 7B model on modest hardware by training small adapter weights over a quantized base — Unsloth handles the training loop efficiently.

Local export & inference

The tuned model is exported to GGUF and served through Ollama, so structured extraction runs entirely on local infrastructure with no external API calls.
