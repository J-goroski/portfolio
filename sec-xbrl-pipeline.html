SEC EDGAR / XBRL Pipeline

Financial-data engineering · Python, SQLite

Overview

A multi-source equity-research data pipeline built on a medallion architecture (Bronze / Silver / Gold) in SQLite. It assembles a coherent, queryable picture of the US equity universe from several public and vendor sources, designed to run offline-first and reproducibly rather than depending on a live cloud stack.

Architecture

Bronze — raw ingestion

Raw pulls land untouched: the US listing universe, end-of-day pricing from two vendors (yFinance and Polygon.io), the SEC EDGAR filing index, and XBRL company facts.

Silver — cleaned & conformed

Raw sources are standardized and cross-referenced — including OpenFIGI enrichment to tie securities together across identifier systems (CIK / CUSIP / ISIN / FIGI).

Gold — analysis-ready

Conformed data is shaped into the tables an equity-research workflow actually queries, so downstream analysis reads from one clean layer.

Why dual-vendor

Pricing is ingested from two independent vendors so values can be cross-validated against each other — the same multi-vendor validation discipline that matters in production reference-data work.
